# Sparr Dashboard (React + Vite)

A responsive React implementation of the Sparr dashboard, based on page 3 (desktop) and page 13 (mobile) of `Wireframe.pdf`.

## Requirements
- Node.js 18+ (recommended: current LTS)
- npm

- `src/main.jsx` — React entry point
